# Reglas compartidas de la bóveda

- Conserva Markdown UTF-8, propiedades YAML y enlaces `[[Wiki]]`.
- Consulta primero `00 - Inicio.md` y carga solo las notas relacionadas.
- No registres conversaciones triviales ni resultados sin verificar.
- Nunca guardes contraseñas, tokens ni credenciales.
- No renombres, muevas o elimines notas sin autorización.
- Cada proyecto nuevo debe residir en `Proyectos/<Nombre>/` y tener una nota índice `00 - <Nombre>.md`.
